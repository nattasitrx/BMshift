# BMshift — เว็บแอพจัดเวรเภสัช

จัดเวรเภสัชรายเดือนอัตโนมัติตามกติกาของหน่วยงาน ใช้บนมือถือได้ หลายคนเข้ามาดูตารางและแจ้ง "ไม่ว่าง / ขออยู่" เองได้โดยไม่ต้อง login (เลือกชื่อตัวเอง)

## หน้าจอ

| แท็บ | ทำอะไร |
|---|---|
| ตารางเวร | ดูตารางรายเดือน, กด **จัดเวร…**, แตะช่องเพื่อแก้ (ต้องเลือกชื่อผู้แก้ บันทึกลงประวัติ) (เลือกผู้จัด + เลือกจัดเฉพาะวันหยุดราชการ / เสริม / เสาร์–อาทิตย์ / วันธรรมดา / ทั้งหมด / ล้าง / ย้อนกลับ — จัดทีละขั้นได้ ขั้นหลังเก็บผลขั้นก่อนและหักยอดให้), แตะช่องเพื่อแก้/แลกเวร, ดูสรุปยอดและประวัติว่าใครกดจัด, พิมพ์ |
| แจ้งวัน | เลือกชื่อตัวเอง แล้วแตะวันที่ "ไม่ว่าง" หรือ "ขออยู่" แยกได้ว่าทั้งวัน / เช้า / บ่าย / ดึก (ไม่ว่างบ่าย = ไม่ได้ SMC ด้วย) · ผู้จัดเวรตั้ง "ลงข้อมูลภายในวันที่…" แล้วกด **แจ้งในกลุ่ม LINE** (เปิด LINE ให้เลือกกลุ่มแล้วส่ง ข้อความมีลิงก์กลับมาหน้านี้) · แต่ละคนติ๊ก "ลงข้อมูลแล้ว" หรือ "ไม่มีวันไม่ว่าง" · ดูได้ว่าใครยังไม่ยืนยัน และกด "เตือนคนที่ยังไม่ยืนยัน" ส่งรายชื่อเข้ากลุ่ม · ตอนกดจัดเวรจะเตือนถ้ายังมีคนไม่ยืนยัน |
| ตลาด | ตลาดเวร: ประกาศขายเวร / หาแลก / รับซื้อ คนที่สนใจกดเสนอ (รับ / แลกกับเวรของตัวเอง / ขายให้) เจ้าของประกาศกด "ตกลง" · คนขายเลือกได้ว่าแก้ชื่อในตาราง (ใบเวรน้อย/เงินตามคนที่อยู่จริง) หรือไม่แก้ชื่อ (เงินเข้าชื่อเดิม โอนกันเอง ช่องในตารางขึ้น 🤝) · ช่องที่มีประกาศขึ้น 🏷️/🔄 · เตือนถ้าผิดกฎ และบันทึกในประวัติ |
| สรุป | ใบเวรน้อย (เฉพาะชื่อจริง): ดูของแต่ละคน และพิมพ์ทุกคนในแผ่นเดียว (A4 แผ่นละ 15 ใบ, ค่าเริ่มต้นเลือกทุกคน) รวมเวร × ค่าเวร (ตั้งค่าในหน้าตั้งค่า เริ่มต้น 820 บาท) · รายคน: เวรทุกวันของเดือน ยอดแต่ละประเภท และคำขอได้ตามขอไหม · แพทเทิร์นสะสม (แตะชื่อดูว่าอยู่อะไร เดือนไหน): ใครอยู่ บ่าย-เช้าดึก / ดึก-เช้าบ่าย / เช้าบ่าย-เช้าดึก, เสริม, หยุดติดกัน/ไม่ติดกัน, ปีใหม่/สงกรานต์ ไปกี่ครั้ง (12 เดือนล่าสุด/ทั้งหมด) |
| เทศกาล | เลือกว่าใครอยู่ปีใหม่/สงกรานต์ แล้วจัดแต่ละเทศกาลแยกไว้ก่อน (แตะตำแหน่งเพื่อเปลี่ยนคน) |
| คิว | ดู/เรียงลำดับคิวทุกประเภท (บนสุด = คิวถัดไป, วงเล็บบอกว่าแต่ละคนใช้ไปล่าสุดเมื่อไหร่) |
| ตั้งค่า | เภสัช (ชื่อเล่น/ชื่อจริง, เพิ่ม/พัก/ลบ, บ่ายต่อดึกได้), วันหยุดราชการ (ปุ่มเติมวันหยุดประจำปี), แพทเทิร์นวันหยุด, สำรองข้อมูล |

**วันหยุดประจำปี**: ปุ่ม "เติมวันหยุดประจำปี" ใส่วันหยุดวันที่ตายตัว วันพระ 4 วัน (คำนวณปฏิทินจันทรคติไทย `src/engine/thaiLunar.ts` ตรวจกับวันที่ประกาศปี 2553–2569 แล้ว) และวันชดเชยให้ วันพระและวันชดเชยที่ต่อกันหลายวันจะติดป้าย "รอตรวจ" จนกว่าจะกดยืนยัน วันหยุดพิเศษตามมติ ครม. และวันพืชมงคลต้องใส่เอง

**พิมพ์**: ได้ตารางฉบับจริง A4 แนวตั้งหน้าเดียว ใช้เฉพาะชื่อจริง (ตัดคำนำหน้าและนามสกุลออกเอง) แสดงเฉพาะเภสัชที่อยู่เวร (ไม่มีข้อมูลไม่ว่าง/ขออยู่) วันที่มี SMC จะแบ่งครึ่งช่องบ่าย (ซ้าย = บ่าย, ขวา = SMC)

## กติกาที่ระบบใช้

**เวร**: ทุกวันมีบ่าย + ดึก · เสาร์–อาทิตย์/วันหยุดราชการ มีเช้า OPD + เช้า IPD + เสริม (IPD 8:30–16:30) เพิ่ม · SMC จันทร์ที่ 1, 3 ของเดือน และทุกวันพุธ (แก้รายวันได้)

**ช่วงวันหยุด** (นับรวมบ่าย/ดึกของคืนก่อนหยุดด้วย) ใช้แพทเทิร์นตามจำนวนวัน
- เสาร์–อาทิตย์ปกติ: 3 คน (A/B/C) + เวรเสริมจากคิว 1 คนทั้ง 2 วัน
- หยุดติดกัน (ติดเสาร์–อาทิตย์ รวมจันทร์/ศุกร์): ใช้คิว "หยุดติดกัน" — คนกลุ่มนี้นับว่าอยู่เสาร์–อาทิตย์ของเดือนนั้นแล้ว
- หยุดไม่ติดกัน (กลางสัปดาห์): ใช้คิว "หยุดไม่ติดกัน"
- ปีใหม่/สงกรานต์: **จัดแยกก่อน** ในแท็บเทศกาล ใช้คนตามที่เลือกไว้ว่าอยู่ปีใหม่หรือสงกรานต์ ระบบเลือกแพทเทิร์นที่จำนวนคนตรงกับกลุ่ม ตอนจัดรายเดือนเวรเทศกาลเป็นเวรตายตัว และถูกนับเข้ายอดก่อนเฉลี่ยเวรที่เหลือ
- เวรเสริมในช่วงวันหยุดราชการใช้คนในแพทเทิร์น (ไม่ดึงคิวเสริม)
- ช่วงหยุดที่คร่อมเดือนจัดทั้งช่วงตอนจัดเดือนแรก แต่ยอดเวรนับตามวันที่จริง

**เสาร์–อาทิตย์ปกติ**: ต้องใช้ 3 × จำนวนสุดสัปดาห์ · คนเกิน → คิว "ไม่อยู่ ส-อา" · คนขาด → คิว "2 wk" · ใครอยู่สุดสัปดาห์ไหนสุ่ม แต่หมุนตำแหน่ง A/B/C ไม่ให้ซ้ำเดือนก่อน (C หนักสุด 4 เวร)

**วันธรรมดา**: เฉลี่ยเวรรวม (OPD+IPD+บ่าย+ดึก ไม่นับเสริม/SMC) และดึกให้เท่ากัน เศษที่หารไม่ลงตัวใช้คิว "เวรรวมเกิน" / "ดึกเกิน" · คนที่ตั้ง "บ่ายต่อดึกได้" จะถูกจัดคู่บ่าย+ดึกวันเดียวกัน

**ห้าม**: ดึกต่อเช้า, ดึกติดกัน, บ่ายต่อดึกวันเดียวกัน (ถ้าไม่ได้ตั้งค่า), SMC ซ้อนบ่าย/ดึก, ลงเวรวันที่แจ้งไม่ว่าง
**พยายามเลี่ยง**: ดึกแล้วบ่ายวันถัดไป, บ่ายแล้วดึกวันถัดไป (วันธรรมดา), เวรติดกันหลายวัน

**คิว**: คนที่ถูกใช้ย้ายไปท้ายคิว คนที่ถูกข้าม (เช่น ไม่ว่าง) อยู่หัวคิวรอรอบถัดไป · กดจัดเดือนเดิมซ้ำจะเริ่มจากคิวก่อนเดือนนั้นเสมอ

## พัฒนา

```bash
npm install
npm run dev      # เปิดแบบออฟไลน์ (ข้อมูลเก็บใน browser)
npm test         # ทดสอบตัวจัดเวร
npm run build
```

- `src/engine/` ตัวจัดเวร (ไม่ขึ้นกับ UI) — `generate.ts` คือขั้นตอนหลัก, `seed.ts` ข้อมูลตั้งต้น (14 คน, คิวจากสมุด, แพทเทิร์น, ตาราง พ.ย. 69)
- `src/ui/` หน้าเว็บ React
- `netlify/functions/` API เก็บข้อมูลกลางบน Netlify Blobs

## Deploy (Netlify)

เชื่อม repo นี้กับ Netlify (build: `npm run build`, publish: `dist`) ข้อมูลจะเก็บใน Netlify Blobs อัตโนมัติ ไม่ต้องตั้งค่าฐานข้อมูลเพิ่ม
